# KrakenScores Volunteer Scorekeeper Guide

This guide is designed to get a new scorekeeper ready in about ten minutes. The scorekeeper account can enter and correct results, but it cannot change teams, pools, times, divisions, or other tournament setup.

## Before the first game

1. Sign in and open **Scorekeeper** from the admin dashboard.
2. Confirm the tournament shown at the top is the tournament you are working.
3. Keep the page open on the device throughout your shift.
4. Check that no red **Offline** banner is showing. If it is, scores remain visible but saving is disabled until the connection returns.

## Find the right game

- **Now** shows games in progress and games whose scheduled playing window includes the current time.
- **Up Next** shows the next scheduled games.
- **Recently Completed** makes it easy to verify or correct the latest results.
- Confirm the game number, pool, division, and both full team names before entering anything. This is especially important when a club fields multiple teams such as Black, Blue, or Yellow.
- Use **Show table** only when you need to search or review the entire schedule.

## Enter a score

1. Select **Start** when play begins.
2. Use the large `−` and `+` controls for Dark and Light. You may also type the score directly.
3. Verify the score against the official table record.
4. Select **Finalize** when the result is official.
5. Wait for the green confirmation. It reports that standings were updated and lists any later games whose participant assignments were filled automatically.

The interface shows **Saving**, **Saved**, or **Error** for each game. Do not close or reload the page while a game says **Saving**. If it says **Error**, confirm the connection and try again; tell the tournament administrator if it continues.

## Correct a result

1. Find the game under **Recently Completed** or in the full table.
2. Select **Correct result**.
3. Enter the official corrected score and finalize it again.
4. Read the impact warning carefully. If later completed games depend on this result, stop and involve the tournament administrator before confirming. Confirmation can reopen and clear those downstream results for review.

Never guess at a correction and never use a later game's result to infer what an earlier official score should have been.

## Delays and pool changes

Tell the tournament administrator which game or pool is affected and the exact delay. Administrators use **Matches → Tournament-day schedule adjustments** to preview and apply a single move or shift all later games in a pool. The app blocks changes that collide with another pool game, a team's other game, or a scheduled break.

Scorekeeper accounts intentionally cannot change the schedule.

## Quick handoff checklist

- [ ] Incoming volunteer is signed in and sees the correct tournament.
- [ ] Internet connection is online; no red banner is visible.
- [ ] Any game currently in progress is identified.
- [ ] Unresolved score disputes or corrections are explained.
- [ ] The tournament administrator's contact method is known.

## Escalate immediately when

- The displayed teams do not match the teams in the pool.
- A score correction warns that completed downstream games will be reopened.
- A game is delayed, moved, cancelled, forfeited, or goes into overtime.
- Saving repeatedly fails after the device is back online.
- You are not certain which game or official score to enter.
